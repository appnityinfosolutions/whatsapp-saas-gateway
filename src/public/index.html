REST API Reference & WhatsApp Chat SDK

Complete guide & interactive code examples to build custom WhatsApp web apps, CRM bots, and messaging workflows

Base URL: http://localhost:3000/api/v1
💬 Send Text 🖼️ Send Media (Images/Docs/Voice) 📋 Get Contact Chats & DP 📜 Get Conversation History ✏️ Edit Contact & Upload DP 🚀 Bulk Broadcast 📱 Session Management ⚡ Real-Time Webhooks & Sockets
POST /api/v1/messages/send-text
Send WhatsApp Message

Send an instant direct text message to any phone number or WhatsApp JID with delivery acknowledgment.

FieldTypeRequiredDescription
sessionIdstringYesActive session UUID
tostringYesPhone number with country code (e.g. 919999846226) or JID
textstringYesMessage text content (emojis, formatting supported)
 
curl -X POST http://localhost:3000/api/v1/messages/send-text \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: YOUR_API_KEY" \
  -d '{
    "sessionId": "YOUR_SESSION_ID",
    "to": "919999846226",
    "text": "Hello! Your booking has been confirmed. 🎉"
  }'
POST /api/v1/messages/send-media
Send Images, Videos, Audio & Docs

Send images, MP4 videos, voice notes (PTT), and documents (PDF, DOCX, ZIP). Supports both hosted URL (mediaUrl) and direct file upload (multipart file form data).

FieldTypeRequiredDescription
sessionIdstringYesActive session UUID
tostringYesRecipient phone number or JID
mediaTypestringYesimage | video | audio | document | sticker
mediaUrlstringOptionalPublicly accessible HTTP/HTTPS URL of the media file
filebinaryOptionalDirect file buffer (when using multipart/form-data upload)
captionstringOptionalText caption attached to the image, video, or document
fileNamestringOptionalFile display name for documents (e.g. Invoice_102.pdf)
Example A: Send using Image / Document URL
curl -X POST http://localhost:3000/api/v1/messages/send-media \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: YOUR_API_KEY" \
  -d '{
    "sessionId": "YOUR_SESSION_ID",
    "to": "919999846226",
    "mediaType": "image",
    "mediaUrl": "https://example.com/photo.jpg",
    "caption": "Here is the product brochure!"
  }'
Example B: Send via Direct Local File Upload (Multipart)
curl -X POST http://localhost:3000/api/v1/messages/send-media \
  -H "X-Api-Key: YOUR_API_KEY" \
  -F "sessionId=YOUR_SESSION_ID" \
  -F "to=919999846226" \
  -F "mediaType=document" \
  -F "file=@/path/to/Invoice.pdf" \
  -F "caption=Attached is your invoice"

Frontend JavaScript / Node.js Socket.IO Connection:
// Connect to live Gateway Socket
const socket = io('http://localhost:3000', {
  auth: { token: 'YOUR_JWT_AUTH_TOKEN' }
});

// Listen for live inbound WhatsApp messages
socket.on('new_message', (msg) => {
  console.log(`New message from ${msg.pushName} (${msg.remoteJid}):`, msg.body);
  if (msg.mediaUrl) {
    console.log(`Media attachment URL: http://localhost:3000${msg.mediaUrl}`);
  }
});

// Listen for session status updates
socket.on('session_status', ({ sessionId, status, phone }) => {
  console.log(`Session ${sessionId} is now ${status} (Number: +${phone})`);
});

Integration in Python, Node.js & PHP

Python (requests):
import requests

API_URL = "http://localhost:3000/api/v1/messages/send-text"
HEADERS = {"X-Api-Key": "YOUR_API_KEY", "Content-Type": "application/json"}

payload = {
    "sessionId": "YOUR_SESSION_ID",
    "to": "919999846226",
    "text": "Hello from Python WhatsApp Bot! 🤖"
}

response = requests.post(API_URL, json=payload, headers=HEADERS)
print(response.json())
Node.js (Fetch API):
const response = await fetch('http://localhost:3000/api/v1/messages/send-text', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-Api-Key': 'YOUR_API_KEY',
  },
  body: JSON.stringify({
    sessionId: 'YOUR_SESSION_ID',
    to: '919999846226',
    text: 'Hello from Node.js server! 🚀',
  }),
});
const data = await response.json();
console.log(data);
